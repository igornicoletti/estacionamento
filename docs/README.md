# Documentação do Projeto

Esta pasta concentra a documentação vigente e os relatórios de validação do projeto.

## Estrutura

- `docs/architecture/`: contratos e decisões arquiteturais vigentes.
- `docs/audits/`: auditorias forenses e inventários reproduzíveis.
- `docs/current/`: documentação operacional e backlog vigente.
- `docs/reports/`: evidências históricas de validação por fluxo.

## Índices

- Arquitetura: `docs/architecture/INDEX__architecture.md`.
- Auditorias: `docs/audits/INDEX__audits.md`.
- Documentação vigente: `docs/current/INDEX__current-docs.md`.
- Backlog de validação de alto impacto (adiado): `docs/current/BACKLOG__high-impact-preprod-validation.md`.
- Relatórios de fluxo executados: `docs/reports/INDEX__flow-reports.md`.

## Convenção de nomes

- Vigente operacional: `YYYY-MM-DD__<tema>.md`
- Índices/backlog: `INDEX__*.md`, `BACKLOG__*.md`
- Nenhum documento temático deve ficar solto diretamente em `docs/`; a raiz contém somente este índice.
