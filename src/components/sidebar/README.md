
# Sidebar

Implementação Radix/shadcn `radix-nova` para a navegação lateral.

Este diretório contém somente responsabilidades da Sidebar:

- marca responsiva;
- grupos e submenus;
- estado ativo;
- badges recebidos por propriedade;
- skeleton;
- triggers responsivos;
- sincronização de altura com o header da página.

Não contém menu de usuário, popover de notificações, sessão ou upload de avatar.
